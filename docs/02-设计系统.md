## 1. 设计基调

一句话：**像一张放在木桌上的手作卡片，而不是一块玻璃屏。**

四条支柱：

| 支柱 | 具体表现 |
| --- | --- |
| **暖** | 米黄底（`#f8f8f0`）、棕字（`#794f27`），没有一处纯白或纯灰 |
| **圆** | 圆角最小 12 px，按钮是全圆角 pill，没有一处直角 |
| **立体** | 交互元素有**实心底部投影**（不是模糊阴影），按下去会「陷进去」 |
| **手作** | 轻微不规则（blob 形弹窗、叶子摆动）、有限但必要的动效 |

### 反面清单（看到就要改）

- ❌ 纯白 `#fff` 大面积背景
- ❌ 直角 / 圆角 < 12 px
- ❌ 扁平无影的卡片
- ❌ 系统蓝 / Material 蓝
- ❌ 细体字（font-weight < 400）
- ❌ 毛玻璃、渐变遮罩、大面积发光
- ❌ 三栏以上信息密度

> 所以在本项目建 `src/styles/tokens.css` 作为**唯一色值来源**，值从这里抄。

  --c-primary-hover:  #3dd4c6;
  --c-primary-active: #50b9ab;
  --c-primary-bg:     #e6f9f6;

  --c-success:        #6fba2c;
  --c-warning:        #f5c31c;
  --c-error:          #e05a5a;

  --c-text:           #794f27;   /* 标题 */
  --c-text-body:      #725d42;   /* 正文 */
  --c-text-secondary: #9f927d;   /* 次要 */
  --c-text-muted:     #8a7b66;   /* 浅 */

  /* ===== 边框 ===== */
  --c-border:         #9f927d;

  --c-focus:          #ffcc00;

  /* ===== 圆角 ===== */
  --r-sm:   12px;
  --r-base: 18px;

### 字体

```css
font-family: Nunito, 'Noto Sans SC', 'Zen Maru Gothic',
  'HarmonyOS Sans SC', 'MiSans',
  -apple-system, 'PingFang SC', 'Hiragino Sans GB',
  'Microsoft YaHei', sans-serif;
```

| 用途 | 字重 |
| --- | --- |
| 正文 | 500 |
| 按钮 / 标题 / 菜单 | 600~700 |
| 数字强调（热量、时钟） | 900 |
| placeholder / 说明 | 400 |

**禁止 < 400 的细体**（中文会发虚）。

| 成功（达标） | `app-green` |
| 装饰 | `app-blue` / `warm-peach-pink` / `brown` |

## 3. 库组件 → 我们的用法

**严格遵守 `参考/animal-island-ui/AI_USAGE.md` 的 props，不要发明。**

| 我们的界面 | 组件 | 用法要点 |
| --- | --- | --- |
| 页面卡片 / 餐次分组 | `Card` | `type="default"`；餐次用 `color` 区分 |
| 空状态容器 | `Card` | `type="dashed"` |
| 主按钮（保存、确认） | `Button` | `type="primary"` |
| 次按钮（取消） | `Button` | `type="default"` |
| 文字按钮（删除、清空） | `Button` | `type="text"` |
| 菜名输入 / 克数输入 | `Input` | `size="large"` 更适合手指 |
| 开关（设置项） | `Switch` | `size="default"` |
| 多选（餐次筛选） | `Checkbox` | |
| 下拉（场景、单位） | `Select` | 受控，`options/value/onChange` 必填 |
| 确认弹窗 / 编辑克数 | `Modal` | 自带 blob 形与打字机，可 `typewriter={false}` |
| 设置分组 / 营养素折叠 | `Collapse` | |
| 周/月切换、餐次切换 | `Tabs` | 叶子摆动动画默认开 |
| 顶部时钟 | `Time` | HUD 风格，放首页 header |
| 图标 | `Icon` | **只有 10 个内置图标**，不够的自绘 |
| 加载中 | `Loading` | |
| 页面底部装饰 | `Footer` | `type="tree"`（森林）或 `"sea"`（海） |
| 空状态文案 | `Typewriter` | 打字机逐字出现 |
| 分隔线 | `Divider` | |
| 游戏光标 | `Cursor` | **移动端不用** |
| 代码块 | `CodeBlock` | 不用 |
| NookPhone 展示 widget | `Phone` | 固定 527×788，**不用**（我们要的是真导航） |

## 5. 页面设计

### 5.1 整体框架 `Shell`

```
┌─────────────────────────────────┐
│  status bar（浅色图标）          │
├─────────────────────────────────┤
│                                 │
│         <Outlet />              │  ← 页面滚动区

```

│                                  │
│  ┌────────────────────────────┐  │
│  │  📷  拍照                  │  │  ← 主按钮，最显眼
│  └────────────────────────────┘  │
│  ┌────────────────────────────┐  │
│  │  ✎  打一句话               │  │
│  └────────────────────────────┘  │

│  ┌──────┬──────┬──────┐          │
│  │米饭  │番茄炒│青菜  │          │  ← 一键复用

## 6. 交互规范

### 6.1 按压反馈（全套）

| 元素 | 常态 | 按下 |
| --- | --- | --- |
| Button | `0 5px 0 0 #bdaea0` | `translateY(2px)` + `0 1px 0 0 #bdaea0` |
| 卡片可点 | `--shadow-card` | `translateY(1px)` + 阴影收紧 |
| ListItem | 透明背景 | 背景 `--c-bg-secondary` |
| Fab | `0 6px 0 0 #0f9c92` | `translateY(3px)` + `0 3px 0 0 #0f9c92` |
| 档位段 | 描边 | `scale(0.97)` |
| 底部导航 | 无 | `translateY(1px)` |

### 6.2 动效清单

```
页面进入       ac-fade-up          250ms
卡片 hover     translateY(-4px)    300ms（桌面端）
数字变化       count-up            600ms ease-out
热量环         stroke-dashoffset   600ms ease-out
条形图         宽度/高度           500ms
Sheet 进出     translateY          280/200ms
Modal          animal-zoom-in      250ms（库自带）
打字机         80ms/字             （库自带）
叶子摆动       （库自带，Tabs）
```

**动效只用于「说明了什么」的地方**：数字变化说明数据更新，环生长说明进度。纯装饰的动画一律不加。

### 6.3 状态设计

| 状态 | 表现 |
| --- | --- |
| 空数据 | `EmptyState`（虚线卡 + SVG + 打字机文案 + 主按钮） |
| 加载中 | `Loading` 组件居中；超过 1s 才显示（避免闪烁） |
| 失败 | 卡片内红色文字 + `Button type="text"`「重试」 |
| 离线 | 顶部一条细提示条，5s 后自动消失，不阻塞操作 |
| AI 低置信 | 条目右侧一个黄色小圆点 + 「建议确认」小字 |

### 6.4 触摸规范

- 所有可点击元素触摸目标 **≥ 44×44**
- 相邻可点元素间距 **≥ 8**
- 滑动删除的触发阈值 **≥ 40px**，并提供撤销 Toast
- 不用 hover-only 的交互（移动端没有 hover）

## 7. 移动端适配

### 7.1 视口与安全区

```css
html, body, #root { height: 100dvh; overflow: hidden; }

.page {
  height: 100%;
  overflow-y: auto;
  padding-bottom: calc(80px + env(safe-area-inset-bottom));
  -webkit-overflow-scrolling: touch;
  overscroll-behavior-y: contain;
}
```

**禁止 `100vh`**（移动浏览器地址栏会导致内容被裁）。

### 7.2 键盘

- 使用 `@capacitor/keyboard` 的 `resize: 'body'`
- 输入框获得焦点时，把它滚进可视区（`scrollIntoView({ block: 'center' })`）
- `Sheet` 内输入时，Sheet 高度压缩而不是被遮挡

### 7.3 手势

| 手势 | 用途 |
| --- | --- |
| 竖向滚动 | 页面 / 列表 |
| 横向滑动 | `DateStrip`、`Tabs` |
| 左滑条目 | 删除 |
| 下拉 | **不实现**（避免和滚动冲突） |
| 双指缩放 | **不实现** |

### 7.4 图标

库只有 10 个内置图标。**不够的必须自绘 SVG**，统一规范：

```
尺寸：24×24（导航）、20×20（内联）、16×16（辅助）
描边：2.2px，圆头圆角（stroke-linecap: round; stroke-linejoin: round）
填充：主体用 currentColor
风格：手绘感 —— 允许轻微不对称，不要几何完美
```

**禁止用 emoji 当图标**（跨设备渲染不一致，且和动森风格不搭）。

## 8. 文案规范

| 场景 | 语气 |
| --- | --- |
| 问候 | 「早上好，今天也要好好吃饭」 |
| 空状态 | 「今天还没有记录哦」 |
| 成功 | 「记下来啦」 |
| 失败 | 「没识别出来，换个说法试试？」 |
| 权限 | 「需要相机权限才能拍照记录」 |

**规则：**

- 用「你」不用「您」
- 不说「操作失败」，说清楚发生了什么
- 一次性文案不超过 20 字
- 中英双语走 i18n，不写死在 JSX

## 9. 实现顺序建议

```
1. tokens.css + global.css          ← 先把令牌落地
2. Shell + BottomNav + Fab          ← 骨架能跑
3. Card / Button / Input 试用         ← 验证库能用
4. ListItem + DateStrip             ← 首页有内容
5. CalorieRing + MacroBar           ← 首页有数据
6. Sheet + SegmentedPortion         ← 录入能走
7. EmptyState / Toast / Loading     ← 补状态
8. Stats 页组件                      ← 本周柱状
```

**先做能跑的骨架，再做漂亮的细节。** 不要一开始就抠圆角和阴影。

## 10. 验收清单

每完成一个页面，对照检查：

- [ ] 没有纯白背景、没有直角、没有细体字
- [ ] 所有可点元素有按压反馈（3D 位移或背景变化）
- [ ] 所有色值来自 `tokens.css`
- [ ] 触摸目标 ≥ 44×44
- [ ] 用 `100dvh`，底部有安全区间距
- [ ] 返回键行为正确（关 Sheet → 回首页 → 退出）
- [ ] 空 / 加载 / 失败 三种状态都有
- [ ] 中文文案没有硬编码在组件里
- [ ] 没有 emoji 当图标
- [ ] 滚动流畅（列表用虚拟化或分页，条目超 100 时）
