# 食岛 · 文档

这里是开发和维护的入口。代码是最终事实；文档描述当前实现，改完行为就顺手改对应文档。

## 先读什么

| 你要做的事 | 先读 |
| --- | --- |
| 跑起来、装到手机 | 根目录 [`README.md`](../README.md) |
| 改模块、找文件、理清调用关系 | [`ARCHITECTURE.md`](ARCHITECTURE.md) |
| 改颜色、字号、间距、组件样式 | [`DESIGN.md`](DESIGN.md) |
| 改录入页面、结果卡、照片删除 | [`ENTRY.md`](ENTRY.md) |
| 改提示词、识别解析、来源标记 | [`AI.md`](AI.md) |
| 改数据源、营养字段、菜谱 | [`DATA.md`](DATA.md) |
| 打包、签名、发版 | [`RELEASE.md`](RELEASE.md) |
| 跑校验、人工验收 | [`TESTING.md`](TESTING.md) |

## 约定

- 不写阶段性交付记录、已删除功能的说明；历史查 git
- 文档里的路径、命令、字段必须能在当前仓库里找到对应实现
- 新增模块或修改数据字段时，同步更新 `ARCHITECTURE.md` / `DATA.md`
- 文档用简体中文；代码标识符、文件名、命令保持原样
