# 校验与验收

## 自动

```bash
npm run typecheck     # TypeScript
npm run check:i18n    # 中英文案键、占位符、空文案
npm run verify        # 纯逻辑回归（含 check:i18n）
```

`npm run verify` 覆盖：

| 组 | 内容 |
| --- | --- |
| search | 成分表条数、别名、拼音、精确模式（醋不命中醋栗）、调味品 kind |
| calc | 克数折算、可食部折算、汇总 |
| stats | 记录天数、日均、最高、供能比、分桶 |
| ai | 菜名 JSON 解析、脏字段兜底、本地优先 / AI 兜底、来源标记 |
| dishes | 菜谱数、比例合计、别名搜索、每 100 g 热量 |
| csv | 表头、逗号与引号转义 |

不引入 Playwright / Cypress；浏览器与真机交互由人工验收。

## 浏览器回归

改动涉及录入、结果卡、照片时，在 `npm run dev` 下人工过一遍：

- 加号 → 三个入口都能进，返回键按层级回退
- 拍照 → 立刻出现记录页 → 识别完成 → 保存 → 首页出现
- 断网识别 → 失败页 → 恢复网络 → 重试成功
- 删除照片后，`Directory.Data/photos` 下没有残留
- 搜索菜谱 → 默认克数 = 配方折算值，改克数时配料按比例缩放
- 我的 → 检查更新：新版 / 已是最新 / 请求失败 三种提示

## 真机清单

装好后按顺序过：

1. 桌面图标完整（盘子，无蓝底、无蓝圈）
2. 冷启动：暖米底 + 居中图标，不闪白
3. 拍照：首次请求相机权限 → 拍照 → 缩略图出现
4. 相册选图：Android 13+ 走系统选择器
5. 识别失败：记录与照片保留，可重试
6. 键盘：搜索框不被遮挡，收起后页面复位
7. 返回键：弹窗/二级页逐级回退，首页退出
8. 导出 CSV：系统分享面板出现，中文不乱码
9. 数据持久：杀掉 App 重开，记录都在
10. 检查更新：下载按钮能拉起浏览器
